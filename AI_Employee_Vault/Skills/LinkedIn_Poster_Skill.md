# LinkedIn Poster Skill

## Description
This skill enables the AI Employee to automatically create and post business updates to LinkedIn for marketing purposes.

## Purpose
- Generate business-focused content for LinkedIn
- Increase business visibility and engagement
- Follow the human-in-the-loop approval process for posts

## Input
- Content to be posted
- Target audience
- Hashtags for the post

## Process
1. Format content appropriately for LinkedIn
2. Create a plan file in the Plans directory
3. Submit for human approval
4. Wait for approval before posting
5. Post to LinkedIn after approval
6. Update dashboard with posting status

## Requirements
- Valid LinkedIn API credentials
- Human approval before posting
- Compliance with LinkedIn's terms of service

## Output
- LinkedIn post published to business profile
- Updated dashboard showing post activity
- Log of post activity
